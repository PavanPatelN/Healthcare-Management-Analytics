# 🏥 Healthcare Management Analytics

A comprehensive end-to-end Data Analytics project that analyzes hospital operations using **SQL Server, Power BI, Excel, and Python**. The project focuses on patient management, doctor performance, appointments, billing, pharmacy inventory, and revenue analysis to generate actionable business insights.

---

## 📌 Project Overview

Healthcare organizations generate large amounts of operational and financial data every day. This project demonstrates how data analytics can be used to analyze hospital performance, improve operational efficiency, monitor financial performance, and support data-driven decision-making.

The project includes SQL-based business analysis, an interactive Power BI dashboard, documentation, and Python-based exploratory data analysis.

---

## 🎯 Business Problem

Hospital management needs a centralized analytics solution to answer important business questions such as:

- How many patients are treated?
- Which departments generate the highest revenue?
- Which doctors handle the most patients?
- What is the average patient waiting time?
- How efficient is the billing process?
- What are the patient demographics?
- How is pharmacy inventory distributed?

---

- Analyze hospital operational data
- Monitor hospital KPIs
- Identify revenue-generating departments

# 💡 Key Business Insights

- Hospital treated 1,000 patients during the analysis period.
- 100 doctors were distributed across 10 medical departments.
- Department-wise revenue analysis identified the highest-performing departments.
- Billing analysis highlighted payment trends and outstanding payments.
- Patient demographic analysis showed gender and city-wise distribution.
- Appointment analysis helped monitor completed, cancelled, and no-show appointments.
- Readmission analysis provided insights into patient follow-up trends.
- Pharmacy inventory analysis supported medicine stock monitoring.

1. Open `Healthcare_Analytics_Analysis.ipynb`
2. Run all cells sequentially.
